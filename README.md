# HR Employee Records Management System

A simple Employee Records Management System built for the LLI technical assessment.

**Stack:** ReactJS + Ant Design · ExpressJS · Microsoft SQL Server · JWT authentication

---

## Features

- **Login** — JWT-based authentication with bcrypt-hashed passwords
- **CRUD** — full create / retrieve / update / delete for employee records
- **Report** — filterable employee report with summary totals and CSV export
- **RESTful API** — resource-based routes with correct HTTP verbs and status codes
